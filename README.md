# Streaming Chatbot

Claude의 답변이 **한 글자씩 실시간으로 나타나는** 챗봇 웹앱입니다.
서버는 Claude API의 스트리밍 응답을 받아 텍스트 스트림으로 전달하고, 프론트엔드는 그 스트림을 직접 읽어 화면에 이어 붙입니다. 매 요청마다 이전 대화를 함께 보내 맥락을 이어 가며, 응답 도중 연결이 끊기거나 사용자가 멈추는 상황까지 처리합니다.

> 🚧 **진행 중** — 대화 기록 저장과 배포를 준비하고 있습니다.

## 기술 스택

- **Next.js 16** (App Router, Route Handler)
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **Claude API** (`@anthropic-ai/sdk`, 개발 중에는 Claude Haiku 5.5)

## 주요 기능

### Claude API 연동 (서버)
- Route Handler가 `client.messages.stream()`으로 Claude에 요청하고, 도착하는 이벤트 중 답변 글자(`text_delta`)만 골라 `text/plain` 스트림으로 흘려보냅니다. 프론트엔드는 Claude의 이벤트 형식을 몰라도 됩니다.
- API 키는 서버 환경 변수로만 읽어 브라우저에 노출되지 않습니다.
- 사용자가 응답을 멈추면 Claude 요청까지 중단해, 아무도 보지 않는 답변에 토큰 비용이 나가지 않게 했습니다.
- 스트리밍 중 발생한 에러는 서버에 기록하고 클라이언트로 전달합니다. 사용자가 멈춘 경우는 에러로 취급하지 않습니다.
- 지금 보내는 질문(500자), Claude에 보내는 대화 전체(10,000자), 답변 길이(`max_tokens`)에 상한을 두어 요청 하나의 최대 비용을 제한합니다.

### 이전 대화 기억 (multi-turn)
Claude API는 이전 요청을 기억하지 않기 때문에, 매 요청마다 지금까지의 대화를 함께 보냅니다.

- **화면용 메시지와 Claude에 보낼 대화를 구분합니다.** 보내기 전에 내용이 빈 말풍선(에러, 중지, 거절로 답을 받지 못한 경우)을 빼고, 화면 전용 필드(`error`, `stopped`)를 떼어 `role`과 `content`만 남깁니다. 중간까지 받고 멈춘 답변은 실제로 오간 대화이므로 남깁니다.
- **서버는 프론트엔드에서 온 값을 믿지 않고 다시 검사합니다.** 배열인지, 원소마다 `role`이 `user` / `assistant`이고 `content`가 비어 있지 않은 문자열인지, 마지막 메시지가 500자 이하의 사용자 질문인지 확인하고, 하나라도 어긋나면 `400`을 돌려줍니다. 길이 합을 구하기 전에 문자열인지부터 확인해, 숫자나 이미지 블록 같은 값으로 길이 제한을 우회할 수 없게 했습니다.
- **대화가 길어지면 오래된 대화부터 잘라 보냅니다.** 전체가 10,000자를 넘으면 가장 최근 메시지부터 거꾸로 길이를 더해 상한 안에 들어가는 만큼만 남깁니다. 거절하는 대신 잘라 내기 때문에 긴 대화도 계속 이어 갈 수 있고, 비용은 상한 안에서 유지됩니다.
  - 중간 메시지를 골라 빼지 않고 최근 대화를 **끊김 없이** 남깁니다. 중간이 빠지면 Claude가 실제로 있었던 적 없는 대화를 읽게 되기 때문입니다.
  - 잘라 낸 뒤에는 대화가 사용자 메시지로 시작하도록 앞쪽의 AI 메시지를 정리합니다.

### 스트리밍 응답 표시
- 메시지를 보내면 빈 AI 말풍선을 먼저 만들고, 서버에서 청크가 도착할 때마다 글자를 이어 붙입니다.
- `fetch` 응답의 `ReadableStream`을 `getReader()`로 직접 읽고, `TextDecoder`로 바이트를 문자열로 변환합니다.
- 한글처럼 여러 바이트로 이루어진 글자가 청크 경계에서 잘려도 깨지지 않도록 `stream` 옵션으로 디코딩합니다.

### 채팅 UI
- 사용자 / AI 메시지를 위치와 색으로 구분하는 말풍선
- 새 메시지가 오면 목록 맨 아래로 자동 스크롤
- 응답을 받는 동안에는 전송 대신 **중지 버튼** 표시 (중복 전송 방지)
- 라이트 / 다크 모드 대응

### 응답 중지
- 답변이 나오는 도중 중지 버튼을 누르면 `AbortController`로 진행 중인 요청을 끊습니다.
- 요청마다 새 `AbortController`를 만들고, `useRef`에 보관해 렌더링이 바뀌어도 같은 요청을 멈출 수 있게 했습니다.
- 사용자가 멈춘 경우(`AbortError`)는 에러와 구분해, 받은 답변은 그대로 두고 회색 안내 문구만 붙입니다.
- 서버도 연결 끊김을 감지해 Claude 요청까지 중단합니다.

### 에러 처리
실패 지점 세 가지를 한 곳에서 처리하며, 모두 AI 말풍선 안에 안내 문구로 표시합니다.

| 상황 | 화면 |
|---|---|
| 요청 자체 실패 (네트워크 오류) | AI 자리에 에러 안내 |
| 서버 에러 응답 (4xx, 5xx) | AI 자리에 에러 안내 |
| 스트리밍 도중 연결 끊김 | **받은 답변은 그대로 두고** 그 아래에 에러 안내 |

에러 문구는 메시지 본문(`content`)과 분리된 화면 전용 필드로 관리해, Claude에 보내는 대화 기록에 섞이지 않습니다.

| 표시 | 의미 | 색 |
|---|---|---|
| 에러 안내 | 응답을 받지 못함 | 빨강 |
| 중지 안내 | 사용자가 직접 멈춤 | 회색 |

## API

프론트엔드와 백엔드는 아래 약속만 공유합니다. 처음에는 가짜 스트리밍 서버로 프론트엔드를 먼저 만들었고, 이후 백엔드를 Claude API로 교체할 때 프론트엔드 코드는 한 줄도 바뀌지 않았습니다. 이전 대화 기억 기능에서 처음으로 약속을 바꿔(`message` → `messages`) 프론트엔드와 백엔드를 함께 수정했습니다.

```
POST /api/chat
Content-Type: application/json

{
  "messages": [
    { "role": "user", "content": "내 이름은 지수야" },
    { "role": "assistant", "content": "반가워요, 지수님!" },
    { "role": "user", "content": "내 이름이 뭐야?" }
  ]
}
```

- **성공**: `200`, `text/plain; charset=utf-8` 스트림으로 답변이 조금씩 도착
- **실패** (`400`)
  - `messages`가 배열이 아니거나 비어 있음
  - `role`이 `user` / `assistant`가 아니거나, `content`가 비어 있지 않은 문자열이 아닌 원소가 있음
  - 마지막 메시지가 사용자 질문이 아니거나 500자를 넘음

## 프로젝트 구조

```
app/                      # 라우팅 전용 (페이지와 API)
├── page.tsx              # 채팅 화면: 입력창, 자동 스크롤, 렌더링
├── layout.tsx
├── globals.css
└── api/chat/route.ts     # 대화를 검사하고 잘라 Claude에 보낸 뒤, 스트리밍 응답을 text/plain으로 전달하는 Route Handler
hooks/
└── useChat.ts            # 메시지 목록, 응답 중 여부, send / stop 제공
lib/                      # React와 무관한 코드
├── streamReply.ts        # 대화를 보내고 스트림을 읽어 청크를 콜백으로 전달
└── messages.ts           # 메시지 배열을 다루는 순수 함수 (withChunk / withError / withStopped, Claude용으로 바꾸는 transformForClaude)
types/
└── chat.ts               # Message(화면용), History(Claude에 보낼 대화) 타입
```

파일은 "무엇에 의존하는가"를 기준으로 나눴고, import는 한 방향으로만 흐릅니다.

```
app/page.tsx → hooks/ → lib/ → types/
```

`lib/`의 함수는 React를 모르기 때문에 화면이나 훅과 상관없이 따로 테스트하거나 재사용할 수 있습니다.

## 실행 방법

1. 패키지를 설치합니다.

   ```bash
   npm install
   ```

2. 프로젝트 루트에 `.env.local` 파일을 만들고 [Claude Console](https://platform.claude.com)에서 발급한 API 키를 넣습니다. 이 파일은 `.gitignore`에 포함되어 커밋되지 않습니다.

   ```
   ANTHROPIC_API_KEY=your-api-key
   ```

3. 개발 서버를 실행하고 [http://localhost:3000](http://localhost:3000)을 엽니다.

   ```bash
   npm run dev
   ```
